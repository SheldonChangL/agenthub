MCP 設定

          
        

        

          把下面的內容存成這個 agent 專案裡的 .mcp.json。
          command 是這台機器上 agenthub-mcp 的絕對路徑，
          -as 是這一列的 session。
        

        

        

        

          這份設定是 per-project 的；同一個目錄下的第二個 Claude Code 會以同一個 session
          身分啟動 agenthub-mcp。每個 session 給自己的設定檔，或用
          --strict-mcp-config 指定獨立的檔。
        

        

          
            這個 session 要能主動送出訊息，還要 owner 開 --outbound
            （ah audience <id> ... --outbound）。

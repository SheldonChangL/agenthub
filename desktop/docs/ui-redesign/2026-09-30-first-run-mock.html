剛裝好時看到的

  • 同一件事出現三次，說法都不一樣。節點沒回應時，待處理列說「節點沒有回應」並給「重試」，清單說「啟動節點」並給「啟動節點」，標題列又是另一句。服務已註冊、程序在跑但節點不回應時，標題列甚至是綠色的「背景服務執行中」：它只看服務有沒有在跑，不看節點有沒有回應。
  • 同時有三到四顆綠色按鈕。清單三步的按鈕全部能按，待處理列再加一顆，看不出下一步是哪個。
  • 第一眼就是技術字。待處理列直接印出 dial tcp 127.0.0.1:7462: connect: connection refused。
  • 清單下面還壓著空表格與 PROVIDER／狀態／公開對象三排 0。
  • 配對抽屜 784 個字。上方步驟條寫「找到對方／送出請求／比對指紋」，下面三段卻是「這台機器能不能被連到／對方在哪裡／比對指紋」；標題說「不廣播」，左欄同時寫「廣播中 · 4:09」；出現本機回路（loopback）、en0、節點設定、手動填入。
  • 候選機器一出現就印完整 node id 和指紋。指紋只有在最後比對時才用得上。
  • 沒有提到另一台電腦也要動手。配對要兩台都操作，畫面只講這一台。
  • 第 3 步「帶我去表格」只是捲到表格，還要自己找公開對象欄。
提案

三步引導

  • 準備這台電腦：一顆按鈕做完「啟動節點＋註冊背景服務＋開放區網」，三個檢查項當場打勾。開放區網是隱私決定，按鈕上寫明位址與影響，可以選「只在這台用」。
  • 連到另一台：第一句就叫你在另一台也打開 AgentHub。找到的機器只顯示名稱、平台和「自稱」標記；送出後等待畫面告訴你對方要按什麼；最後才出現兩組放大的指紋，問「和對方螢幕一樣嗎？」。
  • 分享 session：直接列出這台的 session，勾選、選「能留訊息」或「留訊息並喚醒」，按一次就分享。可以跳過。
  • 引導進行中不顯示主表格、待處理列和篩選。完成或按「稍後再設定」才回到主視窗；之後主視窗保留一顆「繼續設定」。
  • 技術細節全部收進「說明」：位址、node id、指紋來源、手動輸入配對資料。

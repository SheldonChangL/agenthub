# Code of conduct

AgentHub follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text is at that link; this page summarises it and says how to reach
the maintainer.

## In short

- Be respectful and welcoming, whatever someone's background, experience or
  language. Issues and pull requests in English and in 中文 are equally
  welcome.
- Criticise code and ideas, not people. Accept that others may disagree, and
  say so constructively.
- Harassment, insults, sexualised language or imagery, personal or political
  attacks, and publishing someone's private information without their
  permission are not acceptable.
- This applies in the issue tracker, pull requests, discussions, and anywhere
  someone is representing the project.

## Reporting

If someone's behaviour in this project's spaces is a problem, tell the
maintainer privately. GitHub offers no direct messages, so the private channel
on this repository is a
[private advisory](https://github.com/SheldonChangL/agenthub/security/advisories/new):
open one, say it is a conduct report rather than a vulnerability, and describe
what happened. Only you and the repository's maintainers can see it.

Reports are kept confidential. The maintainer may edit or remove comments,
issues and pull requests, and may block a contributor, temporarily or
permanently, as the Contributor Covenant's enforcement guidelines describe.

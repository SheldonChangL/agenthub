按鈕規格

好點、看得出狀態

  • 尺寸：一般 36px、主要 40px、表格列 52px；可點面積不小於 36×36。現在是 28px。
  • 每個畫面一個主要按鈕。綠色只給「下一步該按的那顆」。
  • 按下後立刻換狀態：轉圈＋動詞進行式（「套用中…」），同時停用避免連點。完成時一定有 toast 或原地的結果文字。
  • 停用要說原因。停用鈕旁邊一行小字寫為什麼、怎麼解，不只放在 tooltip。
  • 沒有功能的按鈕不上畫面。隱藏的 btn-reload、重複的開啟配對入口全部拿掉。
  • 鍵盤：焦點外框用藍色 2px；Enter 送出、Esc 關抽屜。
通知分級

三層，各管一件事

待處理列標題列下方，固定不消失，直到事情處理完。每列帶一顆能直接解決它的按鈕：配對請求、收件匣已滿、服務沒在跑、節點連不到。
Toast右下角，回應你剛按的那一下。成功 6 秒後收起（底部有倒數條）；錯誤與警告不會自己消失，並附補救按鈕。
通知中心鈴鐺裡保留本次開啟後的每一則，含時間。錯過 toast 的人在這裡找得到。鈴鐺數字只算未讀的錯誤與待處理。
系統通知視窗不在前景時，配對請求與收件匣已滿另送一則 macOS / Windows 通知，點了回到對應畫面。
